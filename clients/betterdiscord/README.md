Put each .plugin.js file in Settings → BetterDiscord → Plugins → Open Plugins Folder, then enable it. Each plugin works independently. No custom client build or extra plugin library is required.

[Mock + Hidden Channels ZIP](https://github.com/OnlyTripleSix/discord-addons/releases/download/plugins-2026.11.07/BetterDiscord-Mock-HiddenChannels-1.0.0.zip) · [Purge Tools ZIP](https://github.com/OnlyTripleSix/discord-addons/releases/download/plugins-2026.11.07/PurgeTools-BetterDiscord-1.0.0.zip)

When updating, disable a plugin before replacing its file, then enable it again. Keep its configuration file to retain settings.
