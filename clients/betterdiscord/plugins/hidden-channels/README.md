# Hidden Channels for BetterDiscord

Version **1.0.0**. Author: **ItsTripleSix**.

[Download HiddenChannels.plugin.js](https://github.com/OnlyTripleSix/discord-addons/releases/download/plugins-2026.11.07/HiddenChannels.plugin.js) · [Mock + Hidden Channels ZIP](https://github.com/OnlyTripleSix/discord-addons/releases/download/plugins-2026.11.07/BetterDiscord-Mock-HiddenChannels-1.0.0.zip)

Copy the plugin file into Settings → BetterDiscord → Plugins → Open Plugins Folder, then enable HiddenChannels.

Locked channels appear in the channel list with a lock marker. Click a locked row for its cached name, type, category, topic, creation time, channel ID, and permission-rule count. Categories retain their collapsed state.

Right-click a server → **Hidden Channels** opens its full cached list; the same server shortcuts are in the plugin settings. Hidden unread and mention indicators are suppressed locally.

The plugin shows metadata Discord already supplied. It cannot reconstruct withheld names or channels, read locked messages, or grant server permissions. Locked channel history, navigation and voice actions are guarded. Disabling removes its hooks and decorations and restores native list display states.

The user accepted the desktop build before release. The release changes only its version label from the tested beta. MIT License.
