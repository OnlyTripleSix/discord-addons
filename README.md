## Updates and support

Use the build for your client. When updating BetterDiscord Purge Tools, replace its plugin file and keep its configuration file. Valenced packages retain the same plugin IDs as their accepted test builds.

For a problem, include the plugin version, client version, and error or sanitized report. Never post passwords, tokens, or message content.

## Purge Tools notice

Purge Tools permanently removes the messages/reactions you confirm. Preview scans without deleting anything. Discord may restrict accounts for activity it considers automated or abusive. Use at your own risk; the author is not responsible for account restrictions, suspensions, or bans.
